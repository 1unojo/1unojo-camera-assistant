# 1UnOjo Camera Assistant V3

Web app lista para subir al hosting.

## Cómo usar
1. Abre `index.html`.
2. Selecciona cámara en la pestaña **Cámara**.
3. Sube/toma una foto en **Set**.
4. La app calcula recomendaciones de ISO, WB, shutter, codec, gamma y ND.

## Cómo subir al hosting
Sube todos estos archivos al `public_html` o carpeta pública de tu hosting:

- index.html
- style.css
- app.js
- cameras.js
- assets/logo.png

## Nota
Esta versión usa análisis local de imagen, no IA por API todavía. Está preparada para conectar IA después.
